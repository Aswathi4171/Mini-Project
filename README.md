# 🛒 E-commerce Sales and Profitability Analysis

## 📌 Project Overview

This mini project focuses on analysing e-commerce sales data to understand business performance, product sales, regional performance, and profitability.

Microsoft Excel is used for data cleaning and preprocessing, while Power BI is used to create interactive dashboards and visualisations.

The project aims to transform raw sales data into meaningful insights that can support better business decision-making.

## 🎯 Project Objectives

- Analyse overall sales and profit performance.
- Identify the top-performing products.
- Compare sales and profit across regions.
- Analyse monthly sales trends.
- Understand product category performance.
- Calculate and evaluate profit margins.
- Build an interactive Power BI report.

## 🛠️ Tools and Technologies

- **Microsoft Excel** – Data cleaning and preprocessing.
- **Microsoft Power BI** – Data visualisation and dashboard creation.

## 📂 Dataset Information

- Total Records: 500
- Total Columns: 11 (including the calculated Profit Margin column)
- Dataset Type: E-commerce sales data
- Data Period: January 2025 – December 2025

### Key Columns

| Column | Description |
|---|---|
| Order ID | Unique order identifier |
| Order Date | Date of the order |
| Customer ID | Customer identifier |
| Product Name | Name of the product |
| Category | Product category |
| Region | Sales region |
| Quantity | Number of units sold |
| Unit Price | Price per unit |
| Total Sales | Total order sales |
| Profit | Profit generated |
| Profit Margin (%) | Profit percentage |

## 🧹 Data Preprocessing Using Excel

The following preprocessing activities were performed:

- Checked and removed duplicate records.
- Identified and handled missing values.
- Standardised date and numerical formats.
- Standardised category and region names.
- Verified Total Sales using Quantity × Unit Price.
- Created a Profit Margin calculated column.
- Used Excel formulas and data validation techniques.
